# Reed VPN — Дизайн-ТЗ приложения (для дизайнера)

Версия 0.1 (черновик на согласование). Платформы: **Android, Windows, iPhone**.
Стиль: минимализм, одна крупная кнопка-акцент, всё за 1 тап, тёмная тема по умолчанию, бренд Reed (лого обновлённый).
Навигация: нижний таб-бар из **4 вкладок** — Главная · Управление · Личный кабинет · Поддержка.

Обозначения: 🟦 элемент интерфейса · 🔁 состояние · ➡️ переход · 💡 предложение от меня · ❓ вопрос к тебе.

## ЭКРАН 0. Запуск / Онбординг (до авторизации)

Показывается, пока пользователь не привязал Telegram-аккаунт.

**0.1 Приветствие**
- 🟦 По центру сверху: **логотип Reed VPN** (обновлённый) + название «Reed VPN».
- 🟦 Подзаголовок: «Нажмите, чтобы подключиться к временному VPN для регистрации через Telegram».
- 🟦 Кнопка **«Подключиться»** (крупная, акцентная).
  - 🔁 *Не подключен* → текст «Подключиться».
  - 🔁 *Подключается* → спиннер / «Подключаюсь…».
  - 🔁 *Подключен* → меняется на **«Вы подключены»** (зелёная/успех).
  - 🔁 *Ошибка* → «Не удалось подключиться, повторить».
- 🟦 Мелкий **подчёркнутый текст-ссылка** (не кнопка): **«Мне не нужен временный VPN»** — для тех, у кого свой VPN/прокси в ТГ.
- 🟦 После подключения ИЛИ нажатия «мне не нужен» — появляется кнопка **«Зарегистрироваться через Telegram»**.
  - ➡️ Открывает наш Telegram-бот, пользователь жмёт **Start** → создаётся/привязывается личный кабинет → аккаунт в боте связывается с приложением.
- 💡 Нужен макет состояния **«ожидание авторизации»** (пользователь ушёл в ТГ и возвращается) — спиннер «Завершаем вход…» + кнопка «Я нажал(а) Старт».
- 💡 Что показываем, если временный VPN-сервер недоступен — короткий тост/сообщение.
- 💡 Временный VPN: бесплатный, открывает **только Telegram** (для регистрации), используется по WiFi. Дизайн — тот же экран, отдельного не надо.

**Назначение временного VPN:** Telegram в РФ блокируется → пользователь не может открыть бота, чтобы зарегистрироваться/оплатить. Поэтому в приложении встроен бесплатный доступ только к Telegram.

## ВКЛАДКА 1. ГЛАВНАЯ

**1.1 Шапка**
- 🟦 Сверху по центру/слева: «Reed VPN» + новое лого.

**1.2 Блок подписки (верх)**
- 🔁 *Нет подписки / не было покупок*: кнопка **«Получить 3 дня бесплатно»** ➡️ бот (выдаёт пробную).
- 🔁 *Нет активной, пробная уже была*: кнопка **«Купить VPN»**, подпись снизу «от 129 ₽/мес» ➡️ бот (оплата).
- 🔁 *Есть активная подписка*: блок трафика и таймер (см. ниже), кнопка покупки прячется или превращается в маленькую «Продлить».

**1.3 Блок трафика + таймер** (когда есть подписка)
- 🟦 **Два круга/кольца** слева и справа, по кольцу идёт полоса-прогресс:
  - Левое кольцо — **обычный трафик**: «X из 1 ТБ» (индивидуальный) / «X из 2 ТБ» (семейный).
  - Правое кольцо — **LTE-трафик**: «X из 40 ГБ» (или больше, если докупал).
- 🟦 **Между кольцами** — текст: **«Подписка закончится через X дн. X ч. X мин.»** (живой обратный отсчёт).
- 💡 Цвет кольца меняется при заполнении (зелёный → жёлтый → красный); при исчерпании LTE — подпись «LTE закончился, докупить».

**1.4 Кнопка подключения**
- 🟦 **Круглая кнопка без текста** — иконка «power» (вкл/выкл), крупная, по центру.
  - 🔁 *Отключён* — нейтральная (серая/контур).
  - 🔁 *Подключается* — анимация/пульсация.
  - 🔁 *Подключён* — активная (зелёная/свечение) + под кнопкой **таймер сессии** «вы на VPN: 00:12:34».
  - 🔁 *Ошибка* — красная, тост с причиной.
- 💡 Кнопка подключается к **выбранному из списка серверу** (тип подключения = тип сервера, см. 1.6). Отдельного переключателя режима нет.

**1.5 Строка «Локации / Тест»**
- 🟦 Слева — иконка локации + надпись **«Локации»** (💡 варианты названия: «Серверы» / «Страны»).
- 🟦 Справа — кнопка **«Тест пинга / скорости»** (запускает замер по всем серверам).

**1.6 Список серверов** (как в Happ) — **главный способ выбора подключения**
Пользователь сам выбирает сервер из списка; тип подключения определяется самим сервером (настроено на серверах), отдельного переключателя режима НЕТ:
- **SMART-серверы** — обычное прямое подключение (быстро, где нет белых списков).
- **BRIDGE-серверы** — через бридж.
- **LTE-серверы** — для мобильного интернета / обхода белых списков (с ними работает «Сменить оператора»).

Каждая строка:
- **Слева:** флаг страны + название (напр. «🇫🇮 SMART-Финляндия») + **описание** мелким снизу («Прямой доступ. Без рекламы.»).
- **Справа:** **пинг** (мс) + **мигающий кружок**, если пользователь подключён именно к этому серверу (если не подключён — пусто).
- 🟦 Здесь весь список наших серверов: SMART + BRIDGE по странам + LTE-серверы, все вперемешку списком.
- 💡 Тап по серверу — выбрать и подключиться. Долгий тап / иконка ⓘ — детали.
- 💡 Состояние пинга: «—» пока не замерян, цвет по качеству (зелёный/жёлтый/красный).
- 🔁 *Сервер недоступен* — серый, пинг «—», нельзя выбрать.

## ВКЛАДКА 2. УПРАВЛЕНИЕ

- 🟦 **«Сменить оператора»** — для LTE-серверов (подбор рабочих carrier-конфигов под обход белых списков). Экран выбора оператора РФ из списка.
- 🟦 **Трафик** — две кнопки/блока (помимо главного экрана): подробно обычный трафик и LTE (история, остаток, кнопка докупить LTE ➡️ бот).
- 🟦 **Устройства**:
  - Список подключённых устройств (имя, тип: телефон/планшет/ПК/ТВ, последняя активность).
  - Действия: **заблокировать** / **удалить**.
  - **Чёрный список** заблокированных устройств + **разблокировка** (как в ТГ).
  - 💡 Показывать лимит «занято 3 из 5 устройств».
- 💡 **Мои добавления во вкладку:**
  - 🟦 **Split-routing** вкл/выкл (российские сервисы — напрямую мимо VPN).
  - 🟦 **Killswitch** (рубить интернет, если VPN отвалился) — ❓ нужно на старте?
  - 🟦 **Автозапуск** при старте системы / **автоподключение** к последнему серверу.
  - 🟦 Язык, тема (тёмная/светлая).

## ВКЛАДКА 3. ЛИЧНЫЙ КАБИНЕТ

- 🟦 **Профиль Telegram**: аватар, имя, @username (из привязанного аккаунта).
- 🟦 **Текущая подписка**: тариф, статус, «заканчивается через …», тип (индивидуальный/семейный).
- 🟦 Кнопка **«Продлить подписку»** ➡️ оплата в боте.
- 🟦 Кнопка **«Реферальная программа»** — внутри:
  - 💡 Новая механика (вместо реф-ссылки): **«Ввести код друга»** (поле ввода) — привязка к пригласившему.
  - Показ **бонусного баланса** (₽) и сколько приглашено.
  - **«Вывести / потратить бонусы»** (оплата подписки бонусами — через бота).
  - 💡 Свой код-приглашение пользователя тоже показываем (чтобы делиться).
  - ❓ «Вывод средств» — это вывод реальных денег или только оплата подписки бонусами? (сейчас в боте — только оплата подписки).
- 🟦 Кнопка **«Купить LTE-трафик»** ➡️ бот.
- 🟦 Кнопка **«Подарить подписку»** ➡️ бот.
- 🟦 Кнопка **«Улучшить до семейной»** (показывается только для индивидуальных тарифов; доплата разницы) ➡️ бот.
- 💡 **Мои добавления:** «История подписок», «История платежей», «Уведомления» (за 3 дня до конца, истечение, попытка входа заблок. устройства), «Выйти из аккаунта».

  - 💡 Это заметная доработка (нужен бэкенд чата + пуш админу). Реалистично сделать на базе нашего бота: сообщения из приложения форвардятся админу в Telegram, ответы возвращаются в приложение.

## ВИЗУАЛЬНЫЙ СТИЛЬ (для дизайнера)
- Тёмная тема по умолчанию (💡 + светлая опционально).

- Шрифт: ❓ (предложение — Inter / SF Pro / системный).

## СОСТОЯНИЯ И ПУСТЫЕ ЭКРАНЫ (нужны макеты)
1. Не авторизован (онбординг).
2. Авторизован, нет подписки (пробная доступна) → «Получить 3 дня бесплатно».
3. Авторизован, пробная использована, нет активной → «Купить VPN».
4. Активная подписка, отключён от VPN.
5. Активная подписка, подключён (таймер сессии, мигающий сервер).
6. Подписка истекла (баннер «Продлить»).
7. LTE-трафик закончился (баннер «Докупить»).
8. Нет интернета / сервер недоступен.
9. Лимит устройств исчерпан.
10. Устройство заблокировано.
11. Загрузка / ошибка API.
